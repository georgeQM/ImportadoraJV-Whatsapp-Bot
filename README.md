# ImportadoraJV WhatsApp Bot

WhatsApp automation bot built for ImportadoraJV — handles product 
catalog queries and customer interactions via the WhatsApp API.

## Stack
- Node.js / JavaScript
- WhatsApp API (whatsapp-web.js)
- JSON-based product catalog

## What it does
- Responds automatically to customer messages
- Serves product information from a local catalog
- Runs as a lightweight Express server

## Status
Active — used in production for the ImportadoraJV business.
